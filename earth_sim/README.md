# 地球小博士 3D（Three.js）

國小科普互動網頁：自轉、公轉、地軸傾斜與四季、日出日落、月相。

直接用瀏覽器開啟 `index.html` 即可（three.js 與貼圖已內嵌於 `lib/`，不需網路）。

## 兩個視角
- **🌌 太陽系視角**：太陽、地球公轉軌道、四季小地球、月球軌道；可拖曳旋轉／縮放，
  也可「靠近地球」看日夜線、赤道、回歸線、極圈與台灣 📍。
- **🇹🇼 台灣看天空**：站在台灣（23.7°N, 121°E）看白天藍天與雲、日出日落、月亮月相、
  夜晚的星星與星座（北斗七星、仙后座、獵戶座、天蠍座），並畫出今天太陽的路線。

右下角小視窗會同步顯示另一個視角，點一下即可互換。

## 互動
- 日期／時間拉桿、播放速度（10 分鐘/秒 ～ 1 個月/秒）、春分・夏至・秋分・冬至與月相快速跳轉。
- 「實驗室」可調整**地軸傾斜角**（0° 時四季消失）、開關各種輔助線。
- 「小教室」按鈕自動示範：自轉→日夜、公轉→一年、傾斜→四季、回歸線、月相、台灣的一天、星星繞北極星。

## 天文模型（簡化）
地球以四個節氣的真實日期（2026 年）分段內插公轉位置；月相以 29.53 日週期由 2026/1/19 新月推算；
地軸固定指向北極星，太陽直射緯度、日出日落與日長皆由此幾何計算。
